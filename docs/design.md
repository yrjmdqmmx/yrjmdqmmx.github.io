# 页面设计与实现约定

沿用 2026-10-20 用户认可的策划，按直接制作授权推进。以下为制作参考，不冒称用户逐张批准。

## 参考与视觉系统

- `design/home-concept.png`：首页首屏与生活问题入口。
- `design/editorial-concept.png`：三列文章与小行动横幅。
- `design/reading-concept.png`：文章标题、单列正文、目录与收藏。
- 色彩：背景 #F6F2EA，正文 #242B28，朱砂 #9B3D30，松绿 #315E57，边线 #D4D1C7。
- 大标题：中文宋体 / Noto Serif SC，本机 Songti SC、STSong 回退；正文与控件系统无衬线，文章正文可用衬线增强书刊感。
- 页面最大宽 1384px；桌面边距至少 64px，移动端 22px。间距 8/12/16/24/32/48/72/96。
- 首页大屏标题约 60px，文章标题约 50px，正文 20px，行高 1.95；小屏正文 17px，标题缩小而非裁切。
- 图片无蒙版、无叠加色：独立的生成摄影风格插图，与史料明确区分。
- 元素为开放排版、细线、方形按钮；不加圆角卡片容器、阴影、渐变、装饰徽章。
- 图标用统一 1.5px 线性图标：箭头、搜索、收藏、分享、菜单、关闭。

## 文案与结构

首屏文案锁定：
- 日常有来处
- 生活主题 / 小行动 / 阅读清单 / 关于与来源
- 把今天的日子，放进更长的时间里看。
- 从人情、吃饭、居住与忙闲出发，读懂过去，也重新看见自己的生活。
- 从一件小事开始
- 最近，你在为哪件小事费心？
- 试试「随礼」「休息」「买东西」

首页：导航→左右分栏文字与静物摄影→搜索/五主题→三篇主推→小行动横幅→页尾。
主题：搜索与单选主题→结果数量→六篇文章列表→无结果状态。
文章：返回、标题、真实内容背景、六章节、桌面目录→本机实践笔记→匿名反馈与纠错→来源与关联阅读。
小行动：本篇条件、步骤、停止条件、收藏、进入文章实践段落。
阅读清单：文章/行动标签、本机保存解释、空状态、可撤销删除。
关于：编辑边界、来源层级、审核状态、插图说明、隐私与更正。

## 必要的有意调整

- 生成概念中的正文仅作版式参考；真实文章使用已核对原文的策划与新编试读内容，移除概念图擅自生成的“孔子教你”等泛化论断。
- 第二、三张概念擅自添加的导航搜索图标不采用，保留策划中的正文搜索。
- 本机保存、真实反馈、可访问性标签和空状态为已授权功能要求，沿同一视觉系统补齐。
- 素材为当代生活意象，并非历史复原或馆藏照片；在关于页统一标注，文章材料与插图明确分开。
- 六篇为已成文的编辑试读稿，不冒称专业学术复核或正式出版。
- 首页的“从日常出发”维持二级标题比例，未采用局部概念图中接近主标题的大字；文章增加可见审核状态与材料背景，因而正文起点比概念图略低。

## 内容和状态

六篇结构化内容维护于 `src/content/articles.json`。发布状态决定是否公开，草稿不进入浏览列表。
本地服务版本的匿名反馈经 `/api/feedback` 写入 `data/feedback.jsonl`；不公开反馈内容，不提供无认证的后台查询。
收藏和个人笔记仅写浏览器；写入失败须告知用户，不能显示已保存。
不在用户界面暴露开发、框架、服务端路径等实施细节。

## GitHub Pages 托管调整

按静态托管需求，`build:pages` 版本将匿名反馈表单换成 GitHub Issues 链接，明确提示需要账号、提交内容会公开。私人笔记保持仅存在浏览器。关于页同步说明这项差异。

为栏目及每篇公开文章生成实际的 HTML 入口，以支持直接访问、页面刷新和正文锚点；保持现有文章路径。部署只上传 `dist`，不上传运行时数据。`main` 的每次推送通过 Actions 自动构建发布。
