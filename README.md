# 日常有来处

从现代生活问题出发，阅读中国传统文化材料，比较条件差异，再提出可以选择的小行动。

包含 6 篇完整编辑试读稿，内容尚未经过专业学术复核。页面已经区分原始材料、研究解释、本站解读与实践建议。

网站地址：https://yrjmdqmmx.github.io/

## GitHub Pages 发布

网站以静态文件托管在 GitHub Pages，无需数据库或常驻服务器。推送到 `main` 后，GitHub Actions 会自动检查、构建并发布 `dist`。

线上保留搜索、阅读、收藏和私人笔记。内容建议使用 GitHub Issues，**需要登录，提交内容会公开显示**；线上不提供匿名反馈接口。

```sh
npm ci
npm run build:pages
npm run preview:pages
```

静态版预览地址为 http://127.0.0.1:4173 。每篇文章及主要栏目都会生成独立的 HTML 入口，支持直接打开和刷新；保留正常文章网址和段落锚点。

## 本地开发

建议使用 Node.js 22.12 或更新版本。已在本机 Node.js 26.5 环境验证。

```sh
npm install
npm run dev
```

打开 http://127.0.0.1:5173 。默认仅监听本机。

原始本地反馈版本的构建与运行：

```sh
npm run build
npm start
```

`PORT` 可以修改端口。运行前先停止占用相同端口的开发服务。

## 数据在哪里

- 收藏和私人笔记存于当前浏览器的 `richang-library-v1`，不会上传，也不会跨设备同步。笔记需要点击保存。
- 只有运行本地 Node 服务时，匿名反馈才保存在 `data/feedback.jsonl`，每行一条记录；这些数据不上传 GitHub。
- 接口仅保存文章 ID、反馈类型、感受选项（实践反馈）、文字、记录 ID 与时间。不把浏览器私人笔记附带发送，不把 IP 写入反馈文件。
- 反馈没有公开查询接口，也没有管理后台。维护者在本机读取文件进行复核。反馈文件已排除在 Git 之外。
- GitHub Pages 版本仅部署 `dist` 内的静态文件，不部署 `server/` 或 `data/`。线上用户若提出内容建议，由其主动在公开 GitHub Issues 提交。

## 内容维护

内容文件为 `src/content/articles.json`，栏目定义在 `src/content/index.ts`。

每篇文章维护现代场景、时代/地域/对象、历史段落、古今比较、取舍、实践步骤、观察与停止条件、来源定位和更新时间。只有 `status: "published"` 的文章会进入页面。这里的发布状态指是否展示，不代表已经学术审核。

新增内容时：

1. 查原文和篇章上下文，记录支持每个历史判断的具体来源。
2. 确认文献是规范、文学表达、记述还是研究解释，避免当作普遍生活实况。
3. 保持稳定且唯一的文章 ID、来源 ID；历史段落和引文引用对应的来源 ID。
4. 现代建议写明适用条件、成本、可停止的情形；不借古语承诺效果。
5. 核对链接、手机排版，再更新日期。专业审核完成后，才同步修改页面上的审核状态。

AI 生成插图用于当代生活意象，不是史料或历史复原。概念参考保存在 `design/`，视觉约定在 `docs/design.md`，图片生成提示词在 `docs/image-prompts.json`。

## 检查

```sh
npm run check
npm run build:pages
npm test
```

接口测试覆盖反馈落盘、字段过滤、输入校验、来源校验、写入失败与限流；测试使用临时目录。浏览器另行检查真实交互与响应式排版。

技术组成：React、TypeScript、Vite、React Router；Express 仅用于可选的本地反馈版本。正文由客户端渲染，静态入口提供页面标题与描述，不等同于正文服务端渲染。
